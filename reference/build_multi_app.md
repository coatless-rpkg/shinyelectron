# Build multi-app Electron application

Build multi-app Electron application

## Usage

``` r
build_multi_app(
  apps_dir,
  output_dir,
  app_name,
  apps_manifest,
  default_type,
  runtime_strategy,
  sign,
  platform,
  arch,
  icon,
  config,
  overwrite,
  verbose,
  r_packages = NULL,
  r_repos = NULL,
  py_packages = NULL,
  py_index_urls = NULL,
  shinylive_site_dir = NULL
)
```
